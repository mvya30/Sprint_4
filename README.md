2. test_add_new_book_duplicate_name: Цель теста: проверка обработки дубликатов при добавлении книг. Реализация: Попытка добавления одиной и той книги дважды. Проверка, что в словаре осталась только одна запись
3. test_add_new_book_empty_name: Цель теста: проверка обработки добавления пустого названия книги. Реализация: Попытка добаления книги с пустым названием. Проверка, что книга не будет добавлена в колекцию.
4. test_add_new_book_too_long: Цель теста: проверка ограничения ввода длинного имени книги, превышающего максимально допустимую длину. Реализация: Попытка добавления книги с названием в 41 символ. Проверка, что книга не будет добавлена.
5. test_set_book_genre_sets_valid_genre: Цель теста: Проверка установки валидного жанра для существующей книги. Реализация: Для трёх разных книг устанавливаются соответствующие жанры (Фантастика, Ужасы, Комедии). Проверяется, что жанр успешно присваивается книге.
6. test_set_book_genre_nonexistent_book: Цель теста: Проверка установить жанр для несуществующей книги. Реализация: Попытка присвоить жанр книге, которой нет в коллекции. Проверяем, что книга не появится в словаре books_genre.
7. test_get_book_genre_existing: Цель теста: Проверка получения жанра для существующей книги. Реализация: Книге присваивается жанр. Проверяется, что метод возвращает корректный жанр.
8. test_get_with_specific_genre_returns_books: Цель теста: Проверка получения списка книг по определённому жанру. Реализация: Создаются несколько книг с разными жанрами. Проверяется, что для каждого жанра возвращается правильный список книг. 
9. test_get_books_genre_returns_all_books_and_genre: Цель теста: Проверка получения полного словаря книг с их жанрами. Реализация: Добавляется одна книга с жанром, проверяется, что метод возвращает словарь с правильной парой "книга-жанр".
10. test_get_for_children_returns_books_with_child_friendly_genres: Цель теста: Проверка фильтрования книг, подходящих для детей. Реализация: Добавляются книги с разными жанрами. Проверяется, что не возвращаются книги с "взрослыми" жанрами (Детективы, Ужасы). Возвращаются только книги с жанрами, безопасными для детей.
11. test_add_book_in_favorites_success: Цель теста: Проверка успешного добавления книги в избранное. Реализация: Книга добавляется в коллекцию, затем в избранное. Проверяется, что книга присутствует в списке избранного.
12. test_add_book_in_favorites_already_exists: Цель теста: Проверка обработки повторного добавления книги в избранное. Реализация: Книгу дважды добавляем в избранное. Проверяется, что книга будет присутствовать в списке только один раз. 
13. test_delete_book_from_favorites_success: Цель теста: Проверка успешного удаления книги из избранного. Реализация: Книга добавляется в избранное, затем удаляется. Проверяется, что список избранного становится пустым.
14. test_get_list_of_favorites_books: Цель теста: Проверка получения списка избранных книг. Реализация: В коллекцию добавляются две книги, обе добавляются в избранное. Проверяется, что метод возвращает список с этими двумя книгами в правильном порядке.
